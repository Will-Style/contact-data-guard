# Contact Data Guard

MW WP Form / Flamingo に保存されるお問い合わせデータを **全項目暗号化** し、**設定した日数を過ぎたデータを自動削除** する WordPress プラグインです。

- 動作要件: WordPress 5.5 以上 / PHP 7.0 以上（PHP 7.2 未満や sodium 拡張がない環境では WordPress 同梱の sodium_compat を使用）
- 動作確認: WordPress 7.1 + PHP 8.4 + Flamingo 2.6.4 / MW WP Form 4.4.0

## できること

| 機能 | 内容 |
|---|---|
| 暗号化 | 件名・本文・全入力項目・IP などのメタ情報を暗号化して DB に保存（libsodium / XSalsa20-Poly1305） |
| 自動復号 | 鍵があれば、管理画面の一覧・詳細・CSV 出力では今まで通り平文で表示 |
| 自動削除 | 保存から N 日経過したデータを毎日 3:00 頃に完全削除（フォームごとに日数設定、0 = 削除しない） |
| 既存データ | 導入前のデータを管理画面のボタン1つで一括暗号化 |
| 鍵の入れ替え | 旧鍵を残しておけば旧データも読め、一括で新しい鍵に再暗号化可能 |

## 導入手順

1. `contact-data-guard` フォルダを `wp-content/plugins/` にアップロードし、有効化
2. **設定 > お問い合わせデータ保護** を開き、表示された1行を `wp-config.php` に追加
   ```php
   define( 'CDG_ENCRYPTION_KEY', 'base64:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx=' );
   ```
   - 「編集が必要なのはここまでです」より上に書く
   - **鍵はサイトごとに別のものを使う**
   - **鍵はパスワード管理ツールなど、サーバー以外にも必ず保管する（紛失すると復号不可能）**
3. 設定画面で「既存データを暗号化する」をクリック（導入前のデータを暗号化）
4. 保存日数を設定して保存

## 保存期間の設定

- **既定の保存日数**: 個別に指定がないフォームに適用（新しく作ったフォームにも適用）
- **フォームごとの日数**: 空欄 = 既定値に従う / `0` = 削除しない / `1` 以上 = その日数で削除
- 初期状態は「既定 0 = 削除しない」なので、設定するまで何も削除されません
- ゴミ箱・スパムも対象。MW WP Form の添付ファイル（メディア）も一緒に削除
- 1回の実行で最大 3,000 件（残りは翌日）
- 「期限切れデータを今すぐ削除」ボタンで手動実行も可能

## 鍵について

- 鍵があるサーバーでは透過的に暗号化・復号されます。DB だけ漏洩しても鍵がなければ読めません
- DB を別サーバーに移しても、同じ鍵を `wp-config.php` に書けばそのまま読めます
- 鍵がない／違う場合、データは暗号文のまま表示されます（タイトルは「[暗号化データ：鍵がないため表示できません]」）。データ自体は壊れません
- 鍵が未設定の間は新しいデータが **平文で保存** され、管理画面に警告が出ます

### 鍵を入れ替える場合

```php
define( 'CDG_ENCRYPTION_KEY', 'base64:新しい鍵' );
define( 'CDG_PREVIOUS_KEYS', 'base64:旧い鍵' );   // 複数ある場合はカンマ区切り
```
設定画面で「既存データを暗号化する」を実行すると、全データが新しい鍵で再暗号化されます。完了後、`CDG_PREVIOUS_KEYS` は削除してかまいません。

## プラグインを停止・削除するとき

停止すると暗号化されたデータは管理画面で読めなくなります。先に設定画面の「全データを復号して平文に戻す」を実行してから停止してください。
アンインストールしても設定が消えるだけで、お問い合わせデータは削除されません。

## WP-CLI

```bash
wp cdg generate-key          # 新しい鍵を生成して表示
wp cdg status                # 件数・平文項目数・期限切れ件数を表示
wp cdg encrypt               # 既存データを一括暗号化（旧鍵データは再暗号化）
wp cdg decrypt [--yes]       # 全データを平文に戻す
wp cdg cleanup [--dry-run]   # 期限切れデータを削除（--dry-run は件数のみ）
wp cdg decrypt-value 'cdg:v1:...'   # 暗号文を1件復号（鍵の確認用）
```

## 制約・注意点

- **管理画面の検索が効かなくなります**（Flamingo の受信メッセージ検索など）。並べ替えも暗号文の順になります
- **WordPress 本体の「個人データのエクスポート／消去」ツール**はメールアドレス検索ができないため、お問い合わせデータを見つけられません
- **Flamingo アドレス帳**: 暗号化するとメールアドレスで既存連絡先を見つけられず重複登録されるため、既定で新規登録を止めています（設定で変更可）。受信メッセージは通常通り保存されます
- 鍵が違う／ない状態で Flamingo の「スパム」操作をすると Flamingo 側でエラーになります（データは壊れません）
- **添付ファイル**（MW WP Form でメディアに保存したファイル）の中身は暗号化されません（保存期間による削除の対象にはなります）
- **メール本文**は暗号化されません（このプラグインは DB 保存分のみが対象）
- **バックアップ**: 導入前のバックアップには平文データ、削除前のバックアップには削除したデータが残ります
- **WP-Cron** はサイトへのアクセスで動くため、アクセスが少ないサイトではサーバーの cron から `wp cron event run --due-now` を実行するのが確実です
- 暗号化しないメタキー: `_edit_lock` 等の WordPress 管理用、Flamingo の `_hash` `_spam_meta_time` `_last_contacted` `_submission_status`（絞り込み・並べ替えに使われ、個人情報を含まないため）。フィルタ `cdg_is_excluded_meta_key` で変更できます
